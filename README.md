# Python Calculator

A simple Python calculator project created to practise fundamental programming concepts.

# About the Project

This project is a command-line calculator. The user selects an option from a menu and enters numbers to perform a calculation.

The project is intentionally written using beginner-friendly Python so that the code demonstrates an understanding of basic programming rather than advanced techniques.

# Features

- Addition
- Subtraction
- Multiplication
- Division
- Remainder
- Calculation history
- Clear history
- Basic input error handling
- Simple menu system

# Python Concepts Used

- Variables
- Functions
- Lists
- `if`, `elif`, and `else`
- `while` loops
- `for` loops
- User input
- `try` and `except`
- Arithmetic operators

# How to Run

# 1. Install Python

Make sure Python is installed on your computer.

# 2. Open the project

Open the project folder in VS Code or another Python editor.

# 3. Run the program

Open the terminal and run:

```bash
python calculator.py
```

On some systems, use:

```bash
python3 calculator.py
```
